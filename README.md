# Robotics Software Engineering Fundamentals Guide

A comprehensive learning resource for robotics development covering essential technologies from beginner to intermediate level.

## What's Inside

This repository contains detailed explanations and practical guides for:

- **C++** - Core programming concepts for robotics
- **Python** - Scripting and rapid prototyping
- **ROS2** - Robot Operating System 2 fundamentals
- **Linux** - Essential command-line and system knowledge
- **Docker** - Containerization for robotics development
- **Git, Version Control & CI/CD** - Collaborative development and automated testing workflows
- **SLAM** - Simultaneous Localization and Mapping concepts
- **Nav2** - ROS2 Navigation Stack
- **Robotics Transforms Fundamentals** - Coordinate frames, TF2, quaternions, and spatial transformations
- **Machine Learning** - Fundamental ML concepts for robotics
- **PyTorch** - Deep learning framework for computer vision and AI
- **TensorFlow** - Machine learning platform for robotics applications
- **NVIDIA Robotics Stack** - Isaac Sim, Isaac ROS, and GPU-accelerated robotics tools
- **Unity** - Game engine for robotics simulation and visualization

## How to Use This Guide

Each folder contains focused explanations on specific topics. Start with the basics and progress to more advanced concepts:

1. **Linux** - Get comfortable with the command line first
2. **C++** or **Python** - Choose your primary language (or learn both!)
3. **Git, Version Control & CI/CD** - Learn professional development workflows
4. **Docker** - Learn containerization basics
5. **ROS2** - Dive into robot software development
6. **Robotics Transforms Fundamentals** - Master coordinate frames and TF2
7. **SLAM** - Understand mapping and localization
8. **Nav2** - Master autonomous navigation system
9. **Machine Learning** - Learn fundamental ML concepts
10. **PyTorch** / **TensorFlow** - Add AI/ML capabilities to your robots
11. **NVIDIA Robotics Stack** - Explore GPU-accelerated simulation and deployment
12. **Unity** - Explore robotics simulation and visualization
